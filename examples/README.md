# Examples

| File | What it shows |
|---|---|
| [prompts.md](prompts.md) | Ready-to-paste prompts: make a brag from a project or a website, add a voiceover, fix a run, draft the LinkedIn post. |
| [plan.json](plan.json) | A complete `submit_plan` input for a made-up product, with narration, cues and pauses. A test keeps it valid against the real plan checks. |
| [narration.md](narration.md) | How to write voiceover lines: `[pause]`, `{cue}` and pacing, with what the `voiceover` tool reports back. |
| [config.json](config.json) | `~/.smart-control/config.json` with the defaults. Everything in it can also be set in the dashboard under Settings. |
